# **bookworm**
![alt text](./bookworm_logo.jpg)

Your friendly book tracking, note taking app.

**Get it on Google Play:** [Bookworm on Google Play](https://play.google.com/store/apps/details?id=com.busterlock.bookworm) (this is an *actual* working link)

**Get it on Apple Store:** Just joking, too expensive.

## So what the hell does this do

Has this ever happened to you? You're reading a book and then you have a philsophical, life altering revelation, but, oh wait, YOU HAVE NOWHERE TO WRITE IT DOWN! I mean, you do, you could always write it down on a different app LIKE A LOSER.

Or you could use bookworm. A nice, merigold (NOT ORANGE) app that is offline, open source, uses a public API, has no AI, and allows to add vocabulary, notes, cover, keep track of the books you've read, how long did it take, and a nice little dashboard that hypes you up.

We want to be very clear about what bookworm *doesn't do*':
1) We can keep track of the books you read, we can't make you read more
2) We can keep track of new words you learned, we can't teach you how to use them
3) We can help you remember how long did it take you to read a specific book, we can't help you understand anything from the book you've read.

For everything else: bookworm.

Oh is that from another company? Well, whatever. It's open source anyway.

## Things you should know
We don't keep track of user data or sell your data, BUT, Google Fonts (which we use) does track your IP, so, you know, that's a thing you should know. Google tracks you.

## Tech

Built with Flutter, Material 3, and SQLite (sqflite) for local storage.
